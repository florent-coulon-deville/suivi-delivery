« Suivi de la delivery » {{ .Chart.AppVersion }} est installé (installation « {{ .Release.Name }} », espace de noms « {{ .Release.Namespace }} »).

1. Vérifier l'installation :
     helm test {{ .Release.Name }} -n {{ .Release.Namespace }}

2. Ouvrir l'interface :
{{- if and .Values.route.enabled (.Capabilities.APIVersions.Has "route.openshift.io/v1/Route") }}
     https://{{ default "<adresse donnée par OpenShift>" .Values.route.host }}
     (adresse exacte : oc get route {{ include "sd.name" . }} -n {{ .Release.Namespace }} -o jsonpath='{.spec.host}')
{{- else if .Values.ingress.enabled }}
     {{ ternary "https" "http" (not (empty .Values.ingress.tlsSecret)) }}://{{ .Values.ingress.host }}
{{- else }}
     kubectl port-forward -n {{ .Release.Namespace }} service/{{ include "sd.name" . }}-frontend 8080:8080
     puis http://localhost:8080
{{- if .Values.route.enabled }}
     (Route non créée : ce cluster n'est pas un OpenShift.)
{{- end }}
{{- end }}

3. Se connecter avec le compte « admin » (Keycloak démarre en une ou deux minutes la première fois).
{{- if .Values.application.adminPassword }}
     Mot de passe initial : celui de values-secret.yaml.
{{- else }}
     Mot de passe initial :
     kubectl get secret {{ include "sd.applicationSecret" . }} -n {{ .Release.Namespace }} -o jsonpath='{.data.APP_ADMIN_PASSWORD}' | base64 -d; echo
{{- end }}
     Le changer ensuite dans « Mon compte ».

4. Console d'administration de Keycloak (rarement utile, jamais exposée) :
     kubectl port-forward -n {{ .Release.Namespace }} service/{{ include "sd.name" . }}-keycloak 8081:8080
     puis {{ trimSuffix "/" .Values.keycloak.consoleUrl }}/admin (utilisateur admin-keycloak ; mot de passe :
     kubectl get secret {{ include "sd.applicationSecret" . }} -n {{ .Release.Namespace }} -o jsonpath='{.data.KC_BOOTSTRAP_ADMIN_PASSWORD}' | base64 -d; echo)
